# Content planning (R4 and R5)

Read this before drafting substantial new writing. The plan is a working tool: keep it internal unless the user asks to see it, and let the content decide the number and order of paragraphs.

If a blocking gap exists, such as no sources for an R5 task or no real details for a personal statement, stop and ask before planning. Do not plan around missing material.

## Why
Generic writing usually fails at the level of content, not words:
- An opening that restates the prompt.
- Paragraphs that repeat the same idea at different lengths.
- A conclusion that summarises instead of concluding.

Deciding what each paragraph contributes before drafting prevents this.

## Build the plan
Write a compact plan (roughly 150-300 words of notes) with these parts:

- **Purpose** - what the reader should understand, decide or be able to do afterwards.
- **Reader** - level, audience and what they already know.
- **Core** - the thesis, central explanation or answer, stated as a claim rather than a topic ("Caching cuts latency only when the hit rate is high", not "Caching").
- **Paragraphs** - for each one: its job, the one new piece of information it adds, its evidence (source ID, user material, or general background), and an approximate word share.
- **Limits** - caveats or limitations that must appear, and where.
- **Not available** - facts the task needs that the user did not supply. Ask for them, mark them, or leave them out. Never invent them.

Paragraph jobs: frame (a specific angle or stake, not the prompt restated), define, explain mechanism, example, evidence, compare, counterpoint, evaluate, method, result, limitation, recommendation, conclusion.

## Check the plan before drafting
1. Each paragraph adds a different piece of information. Merge or replace any two that overlap.
2. The opening adds something the prompt did not already say.
3. The conclusion's job is an implication, decision, judgement, answer to the question or a limitation-bounded claim - not a summary, unless the user asked for one. Name the new element it delivers.
4. Every factual point has a source: supplied material, a source ID (R5), or genuine general background at this level. Hypothetical examples are labelled as hypothetical.
5. Word shares add up to the target band in `quality-and-length.md`. If they only add up by repeating points, the content is too thin: apply the honest-shortfall rule in SKILL.md instead of padding.
6. Depth matches the level profile (for example, master's work evaluates methods; doctoral work positions a contribution).
7. Paragraph count follows the content. A 250-word answer may need only two or three paragraphs.
8. No title or headings unless the user asked for them or the genre requires them (a report with required sections, for example).

## Draft and check conformance
Draft from the plan in one pass; improve the order if drafting shows a better one. Then check:
- Does each paragraph deliver its planned information?
- Does any paragraph repeat another?
- Does the first sentence merely restate the task?
- Does the conclusion contain its planned new element?
- Was anything from "Not available" filled in anyway? If so, remove it - this is a critical error.

Rewrite only the paragraphs that fail. Style and length repairs share a limit of two rounds (see `quality-and-length.md`). Removing invented or misrepresented content is never limited by that cap.
